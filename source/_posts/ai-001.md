## 搜索算法
### 状态空间图模型
- 1.基本概念：（1）将一个复杂关系表示为若干离散状态（2）将各种关系表示为状态之间的连接（3）所有状态和连接构成状态图

e.g.农夫，狼，羊，白菜过河问题

不妨设F代表农夫，W代表狼，S代表羊，C代表白菜，1代表已渡河状态，0代表未渡河状态

将状态表示为四维向量，那么问题只有10种合理的状态。0000，0001，0010，0100，0101，1010，1011，1101，1110，1111.那么问题就要求从0000到1111

有两种状态图：0000->1010->0010->1110->0100->1101->0101->1111或0000->1010->0010->1011->0001->1101->0101->1111
### 盲目搜索策略
1. DFS搜索过程：
- 沿着左子树一路走到最低子节点
- 若达到最底层依然无解
- 则返回上一父节点
- 更换其他路线
- 示例代码：
```cpp
#include <vector>

using namespace std;
void dfs(int step, int n, vector<int>& path, vector<bool>& used) {
    if (step == n) {
        return;
    }

    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true;
            path.push_back(i);
            dfs(step + 1, n, path, used);
            path.pop_back();
            used[i] = false;
        }
    }
}
```
2. BFS搜索过程：
- 从根节点开始
- 首先考虑同级所有节点状态
- 若同级别均不符合则前进至下一层
- 继续搜索
- 代码示例:
```cpp
void BFS(int start, int target, const vector<vector<int>>& adj) {
    queue<pair<int, int>> q;
    vector<bool> visited(adj.size(), false);

    q.push({start, 0});
    visited[start] = true;

    while (!q.empty()) {
        auto [u, dist] = q.front();
        q.pop();

        if (u == target) {
            return;
        }

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push({v, dist + 1});
            }
        }
    }
}
```
3. 贪心算法
- 总是采用能在当前步骤获得最大收益的选择
- 不考虑全局最优解，只考虑局部最优解，可以被视为一种“盲目”的策略
- 注重搜索速度，但不能保证最优解
```cpp
#include <vector>
#include <algorithm>

struct Activity {
    int start, end;
};

bool cmp(const Activity& a, const Activity& b) {
    return a.end < b.end;
}

int maxActivities(vector<Activity>& acts) {
    sort(acts.begin(), acts.end(), cmp);

    int count = 0;
    int last_end_time = -1;
    for (const auto& act : acts) {
        if (act.start >= last_end_time) {
            count++;
            last_end_time = act.end;
        }
    }
    return count;
}
```
### 启发式搜索
1. 启发函数
- 估计当前状态与目标状态的接近程度
- 表示为一个可量化的函数$h(x)$，也即预估代价
- $g(x)$为已经付出的代价
2. A*算法
- 启发函数中$h(x)$通常使用欧拉距离$(x_1-x_2)^2+(y_1-y_2)^2$或曼哈顿距离$|x_1-x_2|+|y_1-y_2|$
- 示例代码：
```cpp
#include <vector>
#include <queue>
#include <cmath>
#include <iostream>

using namespace std;

struct Node {
    int x, y;
    int g, h;
    int f() const { return g + h; }
    bool operator>(const Node& other) const {
        return f() > other.f();
    }
};

int heuristic(int x, int y, int targetX, int targetY) {
    return abs(x - targetX) + abs(y - targetY);//启发函数采用曼哈顿搜索
}

void astar(int startX, int startY, int targetX, int targetY, const vector<vector<int>>& grid) {
    int rows = grid.size();
    int cols = grid[0].size();
    
    priority_queue<Node, vector<Node>, greater<Node>> openList;
    
    vector<vector<int>> bestG(rows, vector<int>(cols, 1e9));

    openList.push({startX, startY, 0, heuristic(startX, startY, targetX, targetY)});
    bestG[startX][startY] = 0;

    int dx[] = {0, 0, 1, -1};
    int dy[] = {1, -1, 0, 0};

    while (!openList.empty()) {
        Node current = openList.top();
        openList.pop();

        if (current.x == targetX && current.y == targetY) return;

        if (current.g > bestG[current.x][current.y]) continue;

        for (int i = 0; i < 4; ++i) {
            int nx = current.x + dx[i];
            int ny = current.y + dy[i];

            if (nx >= 0 && nx < rows && ny >= 0 && ny < cols && grid[nx][ny] == 0) {
                int newG = current.g + 1;
                if (newG < bestG[nx][ny]) {
                    bestG[nx][ny] = newG;
                    int newH = heuristic(nx, ny, targetX, targetY);
                    openList.push({nx, ny, newG, newH});
                }
            } 
        }
    }
}
```
3. minimax算法（最大最小算法）
- 本质：最大化自身得利，最小化对手得利，适合回合制，不适合需要博弈双方同时做出决策的局面
- 对每个可能局面进行在自己视角下的赋分，对方选择必然为分数最小，则我们需保证在最后一层中自己的分数最高，由此反推局面。
4. $\alpha-\beta$剪枝算法
- 本质通过预先剪枝来减少搜索路径的minimax算法
- 将max叶节点赋值为$-\infty$，min叶节点赋值为$\infty$，最底层的叶节点按照特定启发函数赋值，max要在子节点中寻找最大的赋值，min要在子节点中寻找最小的值
